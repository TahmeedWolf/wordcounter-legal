Word & Character Counter

Privacy Policy

Last updated: August 2026

Word & Character Counter ("the extension") is built with your privacy as the default. This page explains, in plain language, exactly what the extension does and does not do with your data.

What the extension reads

The extension reads text only when you take a direct action:

  • Text you type or paste directly into the popup
  • Text you've highlighted on a page, but only when you click "Use selection" in the popup
  • Text you've highlighted on a page, but only when you right-click it and choose "Count with Word & Character Counter" (Pro feature)

The extension has no access to any other tab, browsing history, or page content, and never reads anything in the background.

What is stored, and where

The extension saves the following, using Chrome's built-in local storage (chrome.storage.local) on your own device only:

  • The last text you typed or counted, so it's there next time you open the popup
  • Your Pro activation status, after a license key is verified

None of this data is sent to us, sold, or shared. It never leaves your device, except as described below.

The one external connection: license verification

If you choose to upgrade to Pro and enter a license key, the extension sends that key to Gumroad's license verification API (api.gumroad.com) to confirm your purchase. This is the only network request the extension ever makes, and it only happens when you actively enter a key and click Activate. Gumroad's handling of that data is governed by Gumroad's own privacy policy.

Notifications and the right-click menu

Pro users can right-click selected text and choose "Count with Word & Character Counter." The result (or a Pro upgrade prompt, for non-Pro users) is shown as a one-time system notification. This happens only when you use that menu item — nothing runs automatically.

No ads, no tracking, no analytics

The extension does not include third-party trackers, analytics scripts, or advertising code of any kind.

Payments

Purchases are handled entirely by Gumroad, not by this extension. We never see or store your payment information. Pro is a one-time payment — no subscription, no recurring charge.

Changes to this policy

If this policy changes, the updated version will be posted at this same URL with a new "last updated" date.
